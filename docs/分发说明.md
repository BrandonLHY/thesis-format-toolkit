# 分发说明

## 交付物在哪里

```
论文格式体检\dist\
├─ 论文格式改写器\                 ← 文件夹版（推荐发给别人）
│   ├─ 论文格式改写器.exe
│   ├─ _internal\                  （运行库，必须一起发）
│   └─ 使用说明.txt
└─ 论文格式改写器_单文件版.exe      ← 单文件版（随手发方便）
```

**发给别人时，文件夹版要把整个文件夹打包压缩后发**，不能只发里面的 exe。

## 两个版本怎么选

| | 文件夹版 | 单文件版 |
|---|---|---|
| 分发方式 | 压缩整个文件夹（约 40 MB） | 发一个 exe（16 MB） |
| 启动速度 | 快 | 慢几秒（每次要先自我解压） |
| 兼容性 | **最好**，不依赖系统临时目录 | 已修复，见下 |
| 建议 | **首选** | 图省事时用 |

单文件版为什么不推荐：它每次启动都要把自己解压到一个目录。

**已做修复**：打包时指定了 `--runtime-tmpdir _MEI_temp`，让它在 exe 自己所在目录解压，
不再依赖系统临时目录。这样即使对方机器的系统临时目录不可写也能启动。
（本机系统临时目录恰好就是坏的，实测修复后可用。）

不过仍建议优先发文件夹版：启动更快、没有解压过程、更不容易被杀毒软件误拦。

**注意**：单文件版会在 exe 旁边创建 `_MEI_temp` 文件夹用于解压，所以 **exe 必须放在有写权限的
目录**。若放在 `C:\Program Files` 下会再次打不开。

## 对方拿到后怎么用

1. 解压到一个**有写权限**的目录（不要放在 `C:\Program Files` 下，否则设定存不下来）
2. 双击 `论文格式改写器.exe`
3. 首次运行若被 Windows 拦截：点「更多信息」→「仍要运行」
4. 详细操作看文件夹里的 `使用说明.txt`

## 环境要求

- 64 位 Windows 7 或更高
- 不需要装 Python、不需要装 Office
- 读取 `.docx`；旧版 `.doc` 需先另存为 `.docx`

## 已知会被 Windows 警告

exe 没有代码签名证书，Windows SmartScreen 大概率会提示"未知发布者"。
这是所有未签名程序的共同情况，不是程序本身有问题。可以让对方：

- 点「更多信息」→「仍要运行」
- 或者右键 exe → 属性 → 勾选「解除锁定」→ 确定

要彻底消除这个提示需要购买代码签名证书（约每年数百到数千元），个人分发一般不做。

## 出问题怎么排查

让对方在程序所在文件夹里按住 **Shift + 右键** →「在此处打开 PowerShell 窗口」，运行：

```powershell
.\论文格式改写器.exe --selftest
```

会在同目录生成 `自检报告.txt`，把这个文件发回来即可定位问题。
自检覆盖 10 项：运行环境、打包模式、python-docx、lxml、tkinter、业务模块、
预设读写、目录可写、端到端改写、图形界面构建。

## 重新打包

改了代码后重新出包：

```powershell
$py = "$env:USERPROFILE\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
& $py build_exe.py            # 两种都打
& $py build_exe.py onedir     # 只打文件夹版
& $py build_exe.py onefile    # 只打单文件版
```

## 数据与隐私

程序全本地运行，不联网、不上传任何内容。改写结果只写到用户自己选的位置。
程序不会修改原始文件。
